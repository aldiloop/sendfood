SendFood · Mockup UI/UX MVP

Usulan visual PWA mobile-first dengan Luna Color Palette. Cakupan layar mengikuti PRD, AFD, DBD, dan backend/API_CONTRACT.md: checkout hanya COD, status pesanan memakai enum backend, tanpa GPS real-time, chat, dompet, voucher, atau rating.

Data contoh. Nama toko, menu, harga, orang, kode pesanan, dan jarak pada mockup ini adalah ilustrasi, bukan data nyata. Gambar makanan diwakili placeholder.

Pelanggan

Jelajah katalog tanpa login. Login diminta sebelum checkout (AFD §2).

Loading, empty, dan error state

Wajib di semua alur (AFD §7, TRD §4). Pesan error RPC dipetakan ke bahasa yang ramah; keranjang tidak dihapus saat checkout gagal.

Penjual

Dashboard berorientasi tindakan: pesanan baru di atas, transisi status sesuai kontrak.

Driver

Hanya tugas yang ditugaskan ke driver tersebut. Tombol status besar, satu aksi per tahap.

Admin

Daftar berbentuk kartu di ponsel. Assignment driver sementara hanya admin.

Aturan pemakaian

Ringkasan keputusan desain untuk ditinjau pemilik frontend.

Warna & kontras

  • #26658C di atas putih dipakai untuk tombol dan tautan (rasio kontras sekitar 6:1).
  • #011C40 untuk teks utama.
  • #A7EBF2 dan #54ACBF hanya untuk latar atau dekorasi. Jangan dipakai untuk teks kecil di atas putih karena kontrasnya rendah.
  • Status selalu memakai ikon dan teks, bukan warna saja.

Label status pesanan

  • pending_seller Menunggu konfirmasi toko
  • accepted Diterima toko · rejected Ditolak toko
  • preparing Sedang disiapkan
  • ready_for_pickup Siap diambil
  • picked_up Sedang diantar · delivered Sampai di tujuan
  • completed Selesai

Belum ditampilkan

  • Transfer manual (manual_transfer_not_configured).
  • Tombol batal pesanan (cancellation_policy_not_configured).
  • Rating, voucher, dompet, chat, GPS real-time (di luar MVP).
  • Estimasi waktu antar dan jam buka, karena belum ada datanya.
  • Kategori menu, karena belum ada kolom kategori di products.

# Send Food — Paket 6 Dokumen

Paket berisi PRD, TRD, AFD, DBD, BSD, dan IPD untuk baseline MVP Send Food.

**Penting:** BSD dan beberapa detail TRD adalah rancangan awal, bukan schema/API yang sudah diterapkan. Cue harus memvalidasi schema, RLS, dan kontrak API di Supabase/Kiro sebelum Muse mengintegrasikannya.

Baca berurutan: PRD → TRD → AFD → DBD → BSD → IPD.

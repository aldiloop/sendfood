# Send Food — Paket 6 Dokumen

Paket berisi PRD, TRD, AFD, DBD, BSD, dan IPD untuk baseline MVP Send Food.

**Penting:** BSD dan beberapa detail TRD adalah rancangan awal, bukan schema/API yang sudah diterapkan. Kiro harus memvalidasi schema, RLS, dan kontrak API di Supabase sebelum frontend mengintegrasikannya.

Seluruh pengembangan, backend maupun frontend, dikerjakan dengan Kiro (lihat [TRD §2](TRD.md#2-kepemilikan-pengembangan)).

Baca berurutan: PRD → TRD → AFD → DBD → BSD → IPD.
